# SSH Key Manager

Скрипт для автоматизации SSH-подключения к Linux-серверу (например, Proxmox VE) с автоматической настройкой ключевой аутентификации.

## Назначение
Автоматизация процесса настройки беспарольного доступа по SSH. Скрипт проверяет наличие локального ключа, при необходимости запрашивает пароль, генерирует новую пару RSA-ключей (4096 бит) и развертывает публичный ключ на удаленном сервере.

## Принцип работы
Алгоритм состоит из 4 основных шагов:
1. **Проверка ключа**: Попытка входа с использованием существующего локального ключа в `./ssh_keys/id_rsa_proxmox`.
2. **Запрос пароля**: Если вход по ключу не удался, скрипт пробует пароль из конфигурации или запрашивает его интерактивно.
3. **Генерация**: После успешного входа по паролю генерируется новая пара RSA-ключей (4096 бит) в оперативной памяти.
4. **Деплой**: Публичный ключ копируется на сервер в `~/.ssh/authorized_keys` (с проверкой на дубликаты), и устанавливаются строгие права доступа (700 для директории, 600 для файла ключей).

## Настройка
Перед запуском отредактируйте переменные в блоке конфигурации внутри функции `main()` в файле `ssh_key_manager.py`:

*   `TARGET_HOST`: IP-адрес или доменное имя сервера.
*   `TARGET_USER`: Имя пользователя (по умолчанию `root`).
*   `PASSWORD`: Пароль (опционально, если не указан — будет запрошен интерактивно).
*   `REMOTE_HOME`: Путь к домашней директории на сервере (например, `/root`).
*   `LOCAL_KEY_DIR`: Директория для хранения ключей на локальной машине (по умолчанию `./ssh_keys`).

## Запуск
```bash
python ssh_key_manager.py
```

## Требования
*   Python 3.9+
*   Библиотека `paramiko`

Установка зависимостей:
```bash
pip install -r requirements.txt
```

## Результат
После первого успешного запуска по паролю, все последующие запуски будут использовать созданный ключ для автоматической аутентификации.
