# SSH Key Manager (v2.3)

Скрипт для автоматизированного управления SSH-ключами на нескольких серверах.

## 1. Назначение
Скрипт предназначен для упрощения настройки беспарольного SSH-доступа к группе серверов (Linux, Proxmox). Он автоматизирует процесс генерации ключей, их безопасной передачи на удаленные узлы и поддержания актуальности списка авторизованных ключей.

## 2. Возможности
- **Автоматическое подключение:** Попытка входа по существующему ключу.
- **Генерация ключей:** Создание RSA-пары (по умолчанию 3072 бит) в современном формате OpenSSH.
- **Интерактивный деплой:** Передача ключа на сервер с использованием пароля (из конфига или вводимого вручную).
- **Умная очистка:** Автоматическое обнаружение и удаление старых ключей данного скрипта (по UUID).
- **Безопасность:** Создание резервной копии `authorized_keys` перед внесением любых изменений.
- **Режим аудита:** Флаг `--show` позволяет проверить доступность всех серверов без изменения файлов.

## 3. Требования
- **ОС:** Windows 10/11 (с поддержкой ANSI), Linux или macOS.
- **Python:** Версия 3.9 и выше.
- **Библиотеки:** `paramiko`.

## 4. Установка
1. Склонируйте репозиторий или скачайте файл скрипта.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
   Или вручную:
   ```bash
   pip install paramiko
   ```

## 5. Первый запуск
1. Запустите скрипт: `python ssh_key_manager.py`.
2. Скрипт создаст файл шаблона `ssh_key_manager.cfg` в своей папке и завершит работу.
3. Откройте `ssh_key_manager.cfg` и заполните данные ваших серверов.
4. Запустите скрипт снова для настройки доступа.

## 6. Конфигурация (ssh_key_manager.cfg)
Конфиг хранится в формате JSON.
- `uuid`: Уникальный ID экземпляра скрипта. Генерируется автоматически.
- `local_key_dir`: Путь к папке с ключами (null = папка `ssh_keys` рядом со скриптом).
- `servers`: Список объектов серверов:
  - `name`: Имя сервера.
  - `host`: IP или домен.
  - `enabled`: `true` (включен) или `false` (пропустить).
  - `username`: Логин (по умолчанию `root`).
  - `password`: Пароль для первого входа (null = интерактивный запрос).
  - `remote_home`: Домашняя папка на сервере (обычно `/root`).
  - `key_size`: Размер ключа (2048, 3072 или 4096).

## 7. Режимы работы
- **Стандартный:** Настраивает доступ к серверам из списка.
- **Аудит:** `python ssh_key_manager.py --show`. Только проверяет, есть ли доступ по ключам.

## 8. Файлы и папки
- `ssh_key_manager.cfg`: Файл настроек.
- `ssh_keys/`: Директория с локальными приватными и публичными ключами.
- `authorized_keys.bak.*`: Резервные копии на удаленном сервере (в папке `~/.ssh/`).

## 9. Использование в проектах
Скрипт спроектирован как автономный инструмент, но функции `connect_and_setup_ssh` и `execute_remote_command` могут быть импортированы в другие Python-проекты для автоматизации SSH-задач.
