# SSH Key Manager (v2.0)

Скрипт для автоматизированного управления SSH-ключами на нескольких серверах с поддержкой UUID-идентификации и очистки старых ключей.

## Основные возможности
- **Централизованная конфигурация:** Все настройки хранятся во внешнем JSON-файле `ssh_manager_id.cfg`.
- **UUID идентификация:** Каждому экземпляру скрипта присваивается уникальный идентификатор, который добавляется в комментарий ключа.
- **Умная очистка:** Скрипт умеет находить свои старые ключи на сервере и предлагать их удаление при обновлении доступа.
- **Безопасный деплой:** Полная перезапись `authorized_keys` с сохранением сторонних ключей.

## Первый запуск
При первом запуске скрипт автоматически создаст файл шаблона `ssh_manager_id.cfg` в своей директории и завершит работу.
Вам необходимо:
1. Открыть `ssh_manager_id.cfg`.
2. Заполнить список `servers` вашими данными.
3. Запустить скрипт снова. При этом `uuid` будет сгенерирован автоматически.

## Конфигурация (ssh_manager_id.cfg)
```json
{
    "uuid": "a1b2c3d4-...",      // Уникальный ID экземпляра (генерируется само)
    "local_key_dir": null,        // Путь к ключам (null = папка ssh_keys рядом)
    "servers": [
        {
            "name": "Server1",    // Имя для файлов и комментариев
            "host": "1.2.3.4",    // IP или домен
            "username": "root",   // Пользователь
            "password": null,     // Пароль (null = интерактивный ввод)
            "remote_home": "/root" // Домашняя папка на сервере
        }
    ]
}
```

## Идентификация ключей
Комментарий ключа теперь имеет расширенный формат:
`{username}@{host}:{server_name}:{uuid}`

Пример:
`root@1.2.3.4:Server1:a1b2c3d4-e5f6-7890-abcd-ef1234567890`

Это позволяет скрипту точно определять, какие ключи на сервере принадлежат именно ему, и безопасно управлять ими, не затрагивая чужие настройки.

## Установка и запуск
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите: `python ssh_key_manager.py`

## Требования
- Python 3.9+
- Paramiko 4.0.0+
