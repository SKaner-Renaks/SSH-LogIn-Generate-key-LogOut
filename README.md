# SSH Key Manager (v2.3)

Скрипт для автоматизированного управления SSH-ключами на нескольких серверах с поддержкой UUID-идентификации, очистки старых ключей и резервного копирования.

## Основные возможности
- **Централизованная конфигурация:** Все настройки хранятся во внешнем JSON-файле `{script_name}.cfg` (например, `ssh_key_manager.cfg`).
- **UUID идентификация:** Каждому экземпляру скрипта присваивается уникальный идентификатор.
- **Умная очистка:** Поиск и удаление устаревших ключей того же экземпляра или других копий скрипта.
- **Безопасность:**
  - Создание резервной копии `authorized_keys` перед любыми изменениями.
  - Поддержка различных длин RSA-ключей (по умолчанию 3072 бит).
  - Возможность проверки доступности без внесения изменений (`--show`).
- **Proxmox-совместимость:** Стандартная длина ключа 3072 бит и бережное отношение к симлинкам.

## Первый запуск
При первом запуске скрипт создаёт файл шаблона `ssh_key_manager.cfg` с уже сгенерированным уникальным UUID.
1. Откройте `.cfg` файл.
2. Настройте список серверов.
3. Запустите скрипт.

## Команды
- `python ssh_key_manager.py` — стандартный запуск (настройка и деплой).
- `python ssh_key_manager.py --show` — только проверка доступности серверов по существующим ключам.

## Конфигурация
```json
{
    "uuid": "a1b2c3d4-...",
    "local_key_dir": null,
    "servers": [
        {
            "name": "Server1",
            "host": "1.2.3.4",
            "enabled": true,
            "username": "root",
            "password": null,
            "remote_home": "/root",
            "key_size": 3072
        }
    ]
}
```

## Требования
- Python 3.9+
- Paramiko 4.0.0+
