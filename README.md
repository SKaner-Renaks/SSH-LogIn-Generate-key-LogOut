# SSH Key Manager

Скрипт для автоматизированного управления SSH-ключами на нескольких серверах (Linux/Proxmox).

## Назначение
Скрипт предназначен для автоматизации настройки беспарольного доступа по SSH. Он полезен при работе с большим количеством серверов или в средах Proxmox VE, где требуется быстрая настройка ключей.

## Принцип работы
1. **Проверка ключа:** Ищет локальный RSA-ключ, специфичный для каждого сервера.
2. **Аутентификация:** Пробует войти по ключу. Если не удается — пробует пароль из конфига или запрашивает его интерактивно.
3. **Генерация:** Если ключа нет, генерирует новую пару RSA-ключей (4096 бит) в формате OpenSSH.
4. **Деплой:** Копирует публичный ключ на сервер, корректно обрабатывая директорию `.ssh` и файл `authorized_keys`.

## Настройка
Параметры серверов задаются в списке `SERVERS` в заголовке скрипта `ssh_key_manager.py`:

```python
SERVERS = [
    {
        "name": "proxmox1",        # Уникальное имя для именования ключа
        "host": "192.168.1.10",    # IP или домен
        "username": "root",        # Логин
        "password": None,          # None для интерактивного ввода
        "remote_home": "/root",    # Домашняя директория на сервере
    },
    # Можно добавить другие серверы...
]
```

Глобальные настройки:
- `LOCAL_KEY_DIR`: Путь к папке с ключами (по умолчанию `ssh_keys` рядом со скриптом).
- `SSH_TIMEOUT`: Таймаут подключения (10 сек).
- `KEY_SIZE`: Размер ключа (4096 бит).

## Запуск
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите скрипт:
   ```bash
   python ssh_key_manager.py
   ```

## Форматы и хранение ключей
- Ключи хранятся в подпапке `ssh_keys/` (добавлена в `.gitignore`).
- Имя файла: `id_rsa_{name}` (например, `id_rsa_proxmox1`).
- Формат: OpenSSH (совместим с современными версиями Paramiko и системными SSH-клиентами).

## Требования
- Python 3.9+
- Paramiko 4.0.0+
- ОС: Windows, Linux, macOS.

## Особенности Proxmox
В Proxmox VE файл `authorized_keys` часто является символической ссылкой на кластерную файловую систему (`/etc/pve/...`). Скрипт учитывает это:
- Не перезаписывает файл целиком, а добавляет ключ через `cat >>`.
- Не изменяет права доступа (`chmod`) на уже существующих файлах, чтобы не нарушить работу кластера.
